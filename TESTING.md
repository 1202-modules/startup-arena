## Ошибки и восстановление

- Превышение капитала (1001 $), недопустимый ввод: ошибка и заблокированное подтверждение, затем успешное исправление.
- 25% свободных, undo, поровну (16667×4 + 16666×2), прежние доли, очистка, весь остаток — проверены через UI.
- Сохранённый черновик после reload; два одинаковых имени запрещены; новый игрок получает 1000 $.
- Подвести итоги → Отмена оставляет event открытым. Неверный пароль показывает ошибку. Активная игра блокирует закрытие даже с правильным паролем.
- Кабинет: неверный пароль, успешный вход, название, повторный вход после перезапуска сервера, CSV и SQLite реально скачаны браузером.
- Скачанный CSV: 11 строк, UTF-8 BOM, суммы до цента. Повторно скачанная исправленная SQLite: 13 результатов, user_version=3, integrity_check=ok; открыта отдельно read-only.
- После закрытия кнопки новой игры нет; серверные записи запрещены. Кабинет создаёт новый event с пустым рейтингом, сохранённые результаты не теряются.
- Реальная остановка API во время открытой формы → локализованная сетевая ошибка; после запуска сервера повторная попытка без reload успешно начала игру с 1000 $.

## Награждение и визуальная приёмка

Проверены 3→2→1, шесть участников с одинаковым третьим местом, единственный победитель, два равных победителя, пустой рейтинг, полный список, replay, пропуск и выключение анимаций. Исправлены прокрутка и слишком высокий список при ничьей; повторные снимки всех трёх мест просмотрены зрением. Конфетти и серебряная/бронзовая/золотая медали видны.

Размеры: 1366×768, 1440×900, 1920×1080; дополнительно 1152×720 для проверки reflow при уменьшенной полезной области. Нет горизонтальной прокрутки; в 1366×768 нижние кнопки карточек доступны. При меньшей высоте используется обычная вертикальная прокрутка. Проверены подробности/история/новости, Escape, focus и подписи графиков, RU/EN, результаты/разбор/кабинет/финалы. Снимки находятся в `docs/implementation/evidence-v2/`, просмотрены встроенным зрением.

Ограничение инструмента: системный `prefers-reduced-motion` и реальный масштаб шрифтов ОС не эмулируются. Пользовательский переключатель анимаций и пропуск проверены браузером; системная ветка покрыта shared проверками и CSS. 1152×720 подтверждает reflow, а не фактический шрифтовой масштаб ОС. Мобильная разработка и тестирование телефонов отменены пользователем.

В консоли всех шести игровых вкладок на завершающем чтении: 0 предупреждений/ошибок и 0 JS-исключений. Ожидаемые отказы ввода, пароля и сети показаны интерфейсом и зафиксированы отдельно.
