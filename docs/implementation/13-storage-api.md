### Уточнение 13.5 до исправления выгрузок
Браузерный download event не появился для Blob URL, хотя ответ API и SQLite snapshot проходили проверки. Транспорт выгрузки меняется на POST /api/organizer/downloads (bearer, файл из фиксированного списка) → одноразовый случайный URL /api/downloads/:ticket. Ticket на 60 секунд, привязан к сроку авторизации и одному файлу, удаляется до выдачи. Пароль и основной token в URL не передаются. Прямые защищённые GET остаются для API. Критерии: анонимная выдача ticket запрещена, неизвестный/истёкший/повторный ticket отвергается, настоящий браузер получает download, CSV/SQLite содержимое проверено автоматически. Это техническое исправление транспорта без изменения продуктовых функций.

### Уточнение 13.5 перед исправлением WAL-снимка
Реальная браузерная выгрузка из файловой тестовой БД скачалась, но открытие снимка завершилось SQLITE_CANTOPEN: serialize сохраняет WAL в байтах 18/19. Предыдущая проверка использовала :memory: и этот случай не покрывала. Согласно https://www.sqlite.org/c3ref/deserialize.html автономный сериализованный снимок следует переводить в rollback-формат, установив эти два байта в 0x01. Исправляется только копия буфера, режим рабочей БД остаётся WAL. Критерии: тест API использует временную файловую WAL-БД; выгруженный буфер и отдельно сохранённый файл открываются, integrity_check=ok, рейтинг и user_version совпадают. После сборки повторить скачивание в браузере и проверку полученного файла.

### Уточнение 13.3 перед исправлением текста разбора
Портфель полностью в свободных деньгах выявил неточный вывод «вложения были распределены»: инвестиций не было. Формула концентрации верна (0%), текст меняется на нейтральный факт «Ни одна компания не занимала большую часть капитала» / «No company held most of the capital». Критерий: утверждение верно и для cash-only, и для распределённых позиций; сами числа и результаты не меняются.
