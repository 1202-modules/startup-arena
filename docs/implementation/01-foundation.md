## Элемент 01.2 — клиент

- Статус: проверен.
- Источник: IMPLEMENTATION_PLAN.md 01.2; PRODUCT_SPEC.md, разделы 1–3; DESIGN_SYSTEM.md.
- Контракт: React + TypeScript + Vite, русская заглушка, рабочий RU/EN, показ доступности сервера; игровой логики нет.
- Фактически изменено: client/index.html, client/src/main.tsx, client/src/App.tsx, client/src/styles.css, client/vite.config.ts.
- Браузер: dev-адрес http://127.0.0.1:5173 и production http://127.0.0.1:3001. Проверены RU, EN, доступный/недоступный API, неизвестный web-адрес и клавиатурный фокус. EN переключает все видимые строки и язык документа; RU остаётся значением по умолчанию.
- Визуальная проверка встроенным зрением: Codex In-app Browser, снимки в журнале задачи, маршрут /, desktop 1366×768 и узкая ширина 390×844. Главный экран читается, карточка и иллюстрация не перекрывают текст, кнопки языка помещаются. Видимый focus ring проверен клавишей Tab.
