### Техническое уточнение запуска
При сверке локальных package manifests выявлено, что Vite8 требует Node≥22.12 (ветка20 не подходит из-за SQLite≥22). Минимум README и engine наших пакетов уточняется до22.12 без изменения поведения игры. Текущая проверка выполнена на26.8.2. Зависимости и runtime не меняются.
