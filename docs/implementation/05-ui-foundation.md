# Этап 05 — интерфейсная основа и локализация

## Паспорт этапа

- Статус: проверен.
- Дата начала: 2026-09-30.
- Зависимости и готовность: этапы 01 и 04 проверены; типизированный игровой API доступен.
- Требования: `DECISIONS.md` (язык и денежная модель), `PRODUCT_SPEC.md` §§3, 8, `GAME_RULES.md` §§1, 4, `I18N.md`, `UI_UX.md`, `IMPLEMENTATION_PLAN.md` §9.
- Цель и результат этапа: подготовить основу React-интерфейса для полного цикла игры — систематизированные токены, оболочка, словари RU/EN, точное отображение денег, общий клиент API, хранение идентификатора игровой сессии и доступная клавиатурная навигация.

- UI/UX поиск: два поиска design-system дали нерелевантные шаблоны (тяжёлый финансовый кабинет и игровая карусель/яркий claymorphism). ## Элемент 05.6 — восстановление игровой сессии

- Статус: проверен.
- Требование и ссылка на источник: `PRODUCT_SPEC.md` §§3, `IMPLEMENTATION_PLAN.md` §9.
- Контракт до реализации: в localStorage хранится только текущий ID сессии; после reload клиент получает актуальный статус и официальные данные с сервера; персональные данные и сценарий рынка локально не кэшируются.
- Критерии приёмки: отсутствующий/повреждённый ID безопасно очищается; недоступная сессия очищает устаревший ID; действующая сессия восстанавливается.
- Затронутые файлы: `client/src/session-recovery.ts` и игровой App следующих этапов.
- Принятое техническое решение и причина: браузерное хранилище используется только как указатель; сервер — источник состояния.
- Что фактически изменено: client/src/session-recovery.ts и App.tsx: локально сохраняется только ID сессии, состояние запрашивается с сервера.
- Отклонение от плана или требований: отсутствует.
- Автоматическая проверка: Серверные тесты переходов/повторных запросов прошли.
- Браузерная проверка: Reload на решении, после результатов 1/2 и на финале восстановил тот же капитал и фазу.
- Визуальная проверка встроенным зрением: Осмотрены восстановленные экран результата и финальный график.
- Отрицательные и повторные запросы: Неизвестный ID удаляется после 404; временная ошибка сети оставляет возможность retry.
- Ограничения и открытые вопросы: активная сессия может быть продолжена на этом компьютере тем, кто его использует; согласуется с офлайн-сценарием.
- Итог: критерии проверены; фактическое поведение соответствует контракту.
