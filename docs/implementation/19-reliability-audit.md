## Элемент 19.1 — Аудит, исправления и совместимость

- Статус: проверен.
- Требование и ссылка на источник: ошибка запроса не должна терять восстанавливаемую сессию (`AGENTS.md`, игровой поток и восстановление; `DECISIONS.md`, игровой поток).
- Контракт до реализации: успешное удаление или подтверждённый 404 очищает локальную сессию; временная сетевая/серверная ошибка оставляет ID и экран активной сессии доступными для повтора и сообщает ошибку.
- Критерии приёмки: тест/браузерный сценарий доказывает, что сбой отмены не теряет ID; успешная отмена очищает его; все существующие проверки проходят.
- Затронутые файлы: предварительно `client/src/App.tsx`, `client/src/api.ts`, аудит исходников `client/src`, `server/src`, `shared/src`, `scripts`, `ops`, `nginx`; при необходимости — релевантные тесты и документация.
- Принятое техническое решение и причина: сохранить текущий REST контракт DELETE; удерживать сессию при неопределённом результате запроса, чтобы повторная попытка могла очистить её после подтверждённого 404.
- Что фактически изменено: `client/src/App.tsx` теперь дожидается очереди автосохранения и очищает локальную сессию только после успешного DELETE; при сетевой ошибке оставляет игрока в сессии и показывает локализованную ошибку. В `client/src/i18n.ts` удалены 52 ключа, на которые не ссылался код интерфейса; plural-формы `playerCount_*` сохранены для автоматического выбора i18next.
- Отклонение от плана или требований: отсутствует.
- Автоматическая проверка: под проектным Node.js 22.23.2 — `npm test` 42/42, `npm run typecheck` exit 0, `npm audit` 0 vulnerabilities, `git diff --check` без замечаний. Первый повторный `npm test` по умолчанию запустился под установленным Node 20.20.2 и завершился SIGSEGV в нативном SQLite; повтор под указанным проектом Node 22 прошёл полностью.
- Браузерная проверка: в изолированном приложении с временной SQLite до исправления отказ DELETE возвращал интерфейс на старт, оставляя серверную сессию `IN_PROGRESS`; после исправления RU и EN оставляли активный экран и ошибку, а повторный успешный DELETE очищал сессию. Затем RU и EN прошли три раунда, завершили игру и начали следующую с общим рейтингом.
- Визуальная проверка встроенным зрением: снимок состояния ошибки проверен; активный экран и сообщение на выбранном языке отображались корректно.
- Отрицательные и повторные запросы: отказ локального API и успешная повторная отмена пройдены; локальная сессия восстановилась после перезагрузки страницы.
- Итоги аудита: помимо исправленного abort-потока, серверные транзакции/переходы и проекции проверены существующими тестами; старые сценарии и проекции v1 необходимы для сохранённых мероприятий. `styles.css` и `play-theme.css` подключены и содержат используемые правила. Статический поиск обнаружил 52 неиспользуемых ключа перевода; они удалены из RU/EN словарей. Новых зависимостей и схемы БД нет.
- Ограничения и открытые вопросы: локальный браузерный путь использовал изолированную SQLite; production участники не менялись. Финальные commit/push, резервирование и deploy ещё ожидают выполнения.
- Итог: исправление и подтверждённая очистка проверены; выпуск остаётся в работе.
