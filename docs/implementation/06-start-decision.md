# Этап 06 — старт и решение по портфелю

## Паспорт этапа

- Статус: проверен.
- Дата начала: 2026-09-30.
- Зависимости и готовность: этапы 04 и 05 проверены; локализация работает через `i18next`/`react-i18next`. Временная недоступность npm registry на раннем этапе устранена до закрытия этапа.
- Требования: `DECISIONS.md`; `PRODUCT_SPEC.md` §§3–5; `GAME_RULES.md` §§1–8; `I18N.md`; `UI_UX.md`; `IMPLEMENTATION_PLAN.md` §10.
- Цель и результат этапа: стартовый экран и экран принятия решения, где игрок видит только текущие сведения, задаёт распределение капитала в целых центах и отправляет его серверу.
