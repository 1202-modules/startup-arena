# Игровые правила и математика

## 1. Начало
Каждый новый игрок всегда получает:

`1000 $`

В серверных расчётах:

`100000` центов.

## 2. Активы
В каждом раунде капитал можно распределить между:
- NovaMind;
- MedFlow;
- VoltX;
- GreenBox;
- AgroPulse;
- OrbitLink;
- свободными деньгами.

Условие:

`NovaMind + MedFlow + VoltX + GreenBox + AgroPulse + OrbitLink + Cash = CurrentCapital`

Все значения неотрицательные.

## 3. Свободные деньги
Свободные деньги:
- не растут;
- не падают;
- доступны для следующего раунда.

Игрок не обязан инвестировать весь капитал.

## 4. Пересчёт раунда
Для каждой компании v2 доходность `r` вычисляется из изменения оценки бизнеса. Сценарий задаёт начальные параметры и внешние шоки; точный расчёт описан в MATHEMATICAL_MODEL.md. Готовая доходность задавалась лишь в исторической версии v1.

Если игрок вложил `I`, то после раунда:

`NewValue = round(I × (1 + r))`

Округление выполняется до целого цента на сервере.

Для реализации доходность задаётся целым числом базисных пунктов (`bps`): `10000 bps = 100%`. Для неотрицательной инвестиции результат считают целочисленно как `floor((I × (10000 + bps) + 5000) / 10000)`. Это округление половины цента вверх; промежуточное произведение не должно терять точность. Значение `bps` не может быть меньше `−10000`.

Общий новый капитал:

`Cash + NewNovaMind + NewMedFlow + NewVoltX + NewGreenBox + NewAgroPulse + NewOrbitLink`

Пример:
- капитал: 1000 $
- NovaMind: 400 $
- MedFlow: 300 $
- Cash: 300 $
- NovaMind: +20%
- MedFlow: -10%

Результат:
- NovaMind: 480 $
- MedFlow: 270 $
- Cash: 300 $
- итог: 1050 $

## 5. Раунды
Ровно 3:
- Раунд 1
- Раунд 2
- Раунд 3

После раундов 1 и 2 игрок может полностью перераспределить новый капитал.
После раунда 3 сессия заканчивается.

## 6. Управление суммой
Основной UX:
- `−100 $`
- `−50 $`
- `+50 $`
- `+100 $`
- ручной ввод
- `Вложить всё свободное`

Допустима кнопка `Поровну` как второстепенное удобство.

Отдельных операций `Купить` и `Продать` нет. Игрок просто задаёт желаемую сумму в компании.

## 7. Информация и причинность
До решения показываются:
- исторические данные;
- текущие показатели;
- нейтральный сигнал.

После подтверждения показываются:
- событие;
- процент изменения;
- результат вложения;
- новый капитал.

Будущая доходность не раскрывается заранее.

## 8. Сценарий мероприятия
Один event использует один scenario.

Несколько игроков могут проходить этот сценарий одновременно; вложения и прогресс одного игрока не меняют рынок и сессии остальных.

Это нужно для честного общего лидерборда: все игроки проходят один и тот же рынок.

Нельзя в одном event выдавать разным игрокам разные сценарии без отдельной системы нормализации результатов.

## 9. Победитель
После закрытия мероприятия участники сортируются по:

`finalCapitalCents DESC`

При точном равенстве капитала допускается одинаковое место.

## 10. Неиспользуемые механики
В MVP отсутствуют:
- комиссии;
- налоги;
- дивиденды;
- акции и штуки акций;
- кредитование;
- шорт;
- маржинальная торговля;
- влияние общего спроса игроков на рынок;
- случайные проценты внутри одного event.

## 11. Дополнительные элементы v2
Один раунд представляет квартал. Предыгровая история не входит в три игровых раунда. Маржа = (выручка − расходы) / выручка. Объяснения и разбор строятся по текущим/сохранённым данным. Новые сценарии используют шесть компаний; сохранения v1 не переоцениваются. Процентные кнопки распределяют выбранную долю свободного остатка, прежние доли сохраняются целочисленным методом наибольших остатков.
