# Локализация v2

Основной язык RU, переключатель RU / EN справа сверху. `client/src/i18n.ts` содержит типизированные словари; английский задаёт полный набор MessageKey, русский проверяется TypeScript. Язык хранится в localStorage. Серверные сигналы, новости, события, объяснения и разбор имеют LocalizedText {ru,en}.

Названия NovaMind, MedFlow, VoltX, GreenBox, AgroPulse, OrbitLink и Startup Arena не переводятся. Имя участника и название мероприятия — пользовательский текст. Остальные кнопки, состояния, ошибки, показатели, отрасли, источники, факт/план, подписи таблиц/графиков, кабинет и церемония локализуются.

Числа и проценты форматируются Intl для ru-RU/en-US. После визуального обновления карточки показывают клиентов и процент выручки после расходов. Подробности показывают исходные показатели с единицами, включая тысячи долларов. Крупный капитал показывается целыми долларами; aria-label и история содержат точную сумму. Инвестиции, свободный остаток, вклад и рейтинг сохраняют центы. Изменения метрик v2 рассчитываются по точным историческим данным до округления для карточки. Неопределённая база изменения — null. SVG имеет доступное текстовое описание значений.

v1 event показывает четыре отрасли и отдельную заметку о старом рынке. i18next и react-i18next инициализируются локальными ресурсами, без загрузки словарей по сети. Типизированная обёртка useI18n проверяет ключи и предоставляет текущий язык.

Обновление 2026-10-02: новые ключи afterCosts / moreControls / chooseHint / resultDetails / yourStart / startups / investmentLabel / completeData / allPlayers переведены RU/EN. Старт, личный итог и результат квартала используют короткий единственный основной заголовок. Названия компаний и пользовательские имена остаются без перевода.
