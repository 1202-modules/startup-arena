# Startup Arena — инвестиционная игра v2

Локальная веб-игра для офлайн-мероприятия: один компьютер, участники по очереди. Каждый начинает ровно с 1000 $, проходит три квартальных раунда и попадает в общий сохраняемый рейтинг.

## Что реализовано

Оформление обновлено 2026-10-02: светлая игровая доска, крупный капитал, два показателя в карточке, подробности по нажатию и простой итог без повторных заголовков.

- Шесть компаний: NovaMind, MedFlow, VoltX, GreenBox, AgroPulse и OrbitLink.
- Шесть скрытых серверных рынков. Изменения бизнеса и доходность вычисляются по целочисленным формулам; один рынок фиксируется на всё мероприятие.
- Предыгровая история, графики, выручка/расходы/маржа/денежный поток, новости с источником и пометкой «факт»/«план».
- Распределение денег: ручной ввод, быстрые суммы и проценты, поровну, отмена, прежние доли, наглядный портфель.
- Анимированные результаты раундов, личный разбор, награждение 3 → 2 → 1 с ничьими и конфетти, пропуск и отключение анимаций.
- RU / EN, восстановление сессии, SQLite, кабинет организатора: название, CSV, резервная копия и следующее мероприятие.

Все изображения и графики — локальные SVG. После установки зависимостей интернет для игры не нужен. Целевой экран — ноутбук/компьютер.

## Запуск из терминала

Node.js 22.12+ и npm. Если зависимости уже установлены и `.env` настроен:

```bash
cd /home/alexey/Projects/startup-invest-game-context
npm run build && npm start
```

Открыть [http://127.0.0.1:3001](http://127.0.0.1:3001). Остановить Ctrl+C. Если `PORT` в `.env` изменён, использовать адрес, который напечатает сервер.

Для первой установки:

1. Выполнить `npm ci` в корне проекта.
2. Если `.env` ещё нет, скопировать `.env.example` в `.env` и задать собственный `ORGANIZER_PASSWORD`. Существующий `.env` не перезаписывать.
3. Выполнить команду запуска выше.

Development: `npm run dev`; открыть адрес Vite из терминала, обычно http://127.0.0.1:5173. API слушает только 127.0.0.1. SQLite находится по `DATABASE_PATH`, по умолчанию `./data/game.sqlite`. При пустой базе event создаётся автоматически; повторный запуск использует сохранённое мероприятие.

## Кабинет и новое мероприятие

На стартовом экране справа сверху нажать **Кабинет организатора** и ввести пароль из `.env`. Для закрытия нажать **Подвести итоги**: пароль запрашивается отдельно, есть **Подтвердить** и **Отмена**. С активным игроком закрытие запрещено.

После закрытия в кабинете доступны **Повторить награждение** и **Новое мероприятие**. Новый event начинает пустой рейтинг и использует рынок v2; старые результаты остаются в базе. Вход в кабинет действует 15 минут, после перезапуска сервера требуется повторный вход. CSV содержит точные суммы до цента; SQLite выгружается как самостоятельный согласованный снимок. Резервную копию следует хранить приватно вместе с данными участников.

Существующие мероприятия v1 сохраняют четыре старых компании и прежние доходности. Для шести компаний завершите старое мероприятие и создайте новое через кабинет. Обновление не переоценивает старые игры. Альтернатива после закрытия: `npm run event:new` при остановленном сервере.

## Проверки и документация

- `npm run typecheck` — типы shared/server/client.
- `npm test` — production build и автоматические проверки математики, денег, БД, API, приватности и экспортов.
- `TESTING.md` — браузерные маршруты и фактические результаты.
- `IMPLEMENTATION_PLAN.md` и `docs/implementation/11-requirements.md` … `15-acceptance-v2.md` — контракты и отчёты по каждому элементу.
- `docs/implementation/16-redesign.md` — отчёт по редизайну и браузерные снимки.
- `MATHEMATICAL_MODEL.md` — формулы, единицы, округление и допущения.
- `docs/research/MARKET_MODEL_RESEARCH.md` — исследование первичных источников.

Источники требований: DECISIONS.md → PRODUCT_SPEC.md → GAME_RULES.md. Архитектура, схема, локализация и интерфейс описаны в ARCHITECTURE.md, DATA_MODEL.md, I18N.md, UI_UX.md и DESIGN_SYSTEM.md.
