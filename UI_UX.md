# Пользовательский путь v2

## Игрок

1. На стартовом экране один заголовок «Соберите свой портфель», имя 2–24 символа, 1000 $, три раунда, игровая доска с шестью продуктами и общий рейтинг.
2. В решении: заметный капитал и три шага прогресса. В карточке текущая ситуация, клиенты и доля выручки после операционных расходов. Подробности показывают полные текущие данные с единицами, историю выручки/издержек, cash, маржу/операционный поток, новости с источником и факт/план, объяснение оценки.
3. Ввести инвестиции, использовать ±50 или весь остаток. «Другие суммы» раскрывает ±100 и 25/50/100% свободных. Cash — автоматический остаток. Поровну, очистить, отменить, прежние доли. Неверный ввод и превышение капитала блокируют подтверждение, черновик не повреждается.
4. Подтвердить: анимированный капитал и долларовый вклад каждой компании, процент рынка, событие и причинные изменения. Следующий квартал повторяет цикл.
5. После третьего: один заголовок «Ваш результат», капитал, доходность и место. Кнопка следующего игрока сразу под капиталом. История и краткие наблюдения видны; вклады компаний и собственные распределения раскрываются в «Истории ваших решений». Следующий игрок начинает с 1000 $.

Автосохранение через 450 ms; при обновлении восстанавливается серверное состояние. Временная ошибка сервера показывает локализованный текст, повтор сохраняет/подтверждает идемпотентно. Активная игра скрывает кабинет, чтобы не мешать участнику.

## Организатор

Кнопка справа сверху открывает кабинет по паролю: название, состояние/число завершённых/активных, CSV, SQLite копия. Закрытие всегда требует отдельный пароль с Подтвердить и Отмена. Активный участник запрещает закрытие. После закрытия можно создать новый event с сохранением истории или повторить церемонию. Авторизация только в памяти, 15 минут.

## Финальная церемония

3-е, 2-е, 1-е место показываются только если такие ранги существуют. Ничьи показывают всех участников соответствующего места. Для первого — золотая медаль и конфетти, затем полный рейтинг. Пустой event сразу показывает пустой рейтинг. Пропуск, отключение анимаций и повтор доступны.

## Экран и язык

Цель — один наш ноутбук/компьютер; мобильная версия и телефоны отменены пользователем. Целевые размеры 1366×768, 1440×900, 1920×1080; RU/EN, клавиатура, focus и вертикальная прокрутка при масштабе. Рабочие состояния подтверждаются браузерными снимками, не только DOM. Скриншоты содержат исключительно синтетические тестовые имена.
