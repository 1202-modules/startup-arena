# Подробный план реализации v2

Дата: 2026-10-01. Источники требований: DECISIONS.md, PRODUCT_SPEC.md, GAME_RULES.md. Этапы 00–10 — исторический выпуск v1; их план сохранён в docs/implementation/legacy-plan-v1.md.

Инварианты: одно устройство, один активный игрок, 100000 центов, три раунда, шесть компаний в новых event, общий скрытый формульный рынок, RU/EN, offline. Существующие event v1 сохраняются.

До кода каждого этапа подготовлен отдельный отчёт по TEMPLATE.md. Элемент не считается завершённым до проверок. Порядок: 11 → 12 → 13 → 14 → 15; исследование 12.1 выполнено субагентом. Итоги приёмки: 36 автоматических проверок и 24 браузерные игры; ограничения инструмента явно записаны в TESTING.md.
