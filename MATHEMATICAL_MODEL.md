# Математическая модель v2

Реализация: `server/src/scenarios/model.ts`, `generated.ts`. Исследование структуры и первичных источников: `docs/research/MARKET_MODEL_RESEARCH.md` (субагент GPT-6.1-Sol, high). Параметры компаний и шоки вымышлены; они не являются статистической калибровкой реальных стартапов.

## Единицы и округление

Все деньги — целые центы; коэффициенты — целые базисные пункты (10000 = 100%). Промежуточные произведения и дисконтирование — BigInt. `round(n/d)` округляет половину от нуля, знаменатель положителен. На границе JSON значения проверяются на safe integer. Невалидные параметры отвергаются. Изменение относительно нуля неопределено: API показывает `null`, расчёт доходности требует положительной исходной оценки.

## Состояние бизнеса

C — число оплачиваемых единиц, A — месячная выручка на единицу, U — месячные переменные расходы на единицу, F — постоянные месячные расходы, K — cash, D — дефицит финансирования, g — последний темп роста, M — мультипликатор годовой выручки.

| Компания | Оплачиваемая единица |
| --- | --- |
| NovaMind | корпоративная подписка |
| MedFlow | подключённое медицинское подразделение |
| VoltX | обслуживаемая установка накопителя |
| GreenBox | обслуживаемая торговая/логистическая площадка сети |
| AgroPulse | хозяйство или оплачиваемый участок внедрения |
| OrbitLink | корпоративное подключение |

В интерфейсе используется общий короткий показатель «Клиенты». Это не всегда юридическое лицо: прекращение договора сети может отключить множество площадок.

## Операции и переход квартала

- Месячная выручка `R = C × A`.
- Месячные расходы `E = C × U + F`.
- Операционная маржа `round((R − E) × 10000 / R)`; при нулевой выручке технически 0, в каталоге выручка положительна.
- Операционный поток квартала `OCF = 3 × (R − E)`.
- Шок b меняет показатель X: `X' = round(X × (10000+b) / 10000)`. Отдельные шоки задают клиентов, A, U, F и M.
- Поддерживающие вложения `H = round(3 × R' × h / 10000)`; дополнительные вложения J задаёт сценарий.
- Чистый запас `N = K − D + OCF' − H − J`.
- `K' = max(0,N)`, `D' = max(0,−N)`; cash и дефицит одновременно положительными не бывают.

Дефицит финансирования — обязательство бизнеса, а не кредит игрока. Учебное допущение: автоматическое беспроцентное финансирование и погашение из будущего потока. Налоги, оборотный капитал, амортизация и проценты опущены.

## Оценка бизнеса

Берётся **текущее** состояние, не будущие шоки скрытого сценария. Прогноз роста `g* = clamp(g,−2500,3500)` фиксирован на четыре квартала. Для каждого q=1..4 число клиентов последовательно округляется по g*, A/U/F постоянны. Это допущение о запасе производственной мощности; расширение мощности представлено отдельными фактическими вложениями J в сценарии.

- `FCFq = 3 × (Rq − Eq) − round(3 × Rq × h / 10000)`.
- `PVq = round(FCFq × 10000^q / (10000+d)^q)`.
- `T = round(12 × R4 × M / 10000)` — терминальная стоимость по годовой выручке.
- `PVT = round(T × 10000^4 / (10000+d)^4)`.
- Оценка собственного капитала `V = max(0,K − D + ΣPVq + PVT)`.

Знаменатель и числитель дисконта накапливаются как точные целые, коэффициент не округляется до bps на каждом квартале. Каждый поток округляется до цента отдельно. Фактический и прогнозный поток используют одинаковые поддерживающие вложения H.

| Компания | Квартальный дисконт d, bps | Поддерживающие вложения h, bps |
| --- | ---: | ---: |
| NovaMind | 550 | 300 |
| MedFlow | 350 | 200 |
| VoltX | 750 | 1100 |
| GreenBox | 450 | 500 |
| AgroPulse | 600 | 800 |
| OrbitLink | 800 | 1500 |

Эти коэффициенты — настройки учебного рынка. Более капиталоёмкие отрасли требуют большей доли вложений. Они не выдаются за текущие ставки конкретных реальных компаний.

## Доходность и деньги игрока

Доходность `r = round((V'−V) × 10000 / V)`. Исходная V обязана быть положительна в каждом игровом переходе; V'=0 даёт −10000 bps. Нулевая оценка не получает выдуманную нулевую доходность. Все 108 переходов каталога автоматически проверяются.

Позиция I: `I' = floor((I × (10000+r) + 5000) / 10000)`. Капитал после раунда — cash игрока плюс сумма I'. Доходности округляются до bps, поэтому индекс исторической оценки бизнеса и накопленная стоимость инвестиций могут отличаться на округление; оба имеют отдельные подписи.

Распределение «поровну» и «прежние доли» использует метод наибольших остатков: целые частные, оставшиеся центы по убыванию дробного остатка с устойчивым порядком. Сумма всегда ровно равна капиталу.

## Независимый контрольный пример

1000 единиц, A=100 $, U=80 $, F=10000 $/месяц, K=500000 $, D=0, g=0, M=1.5, d=5%/квартал, h=3%.
R=100000 $, E=90000 $, OCF=30000 $, H=9000 $, FCF каждого квартала=21000 $, T=1800000 $. После округления каждого дисконтированного потока V=**2055329.41 $**. Дополнительные вложения следующего квартала 100000 $ дают K'=421000 $ и V'=**1976329.41 $**, r=−384 bps. Проверено golden test, независимо рассчитанный пример из исследования.

## История, новости и границы

Четыре предыгровых перехода создают пять снимков −4..0 по тем же формулам. Затем три игровых перехода. Сервер отдаёт только снимки с period≤round−1 и результаты завершённых раундов. Внутренние states/shocks/parameters/будущие события не входят в DTO или bundle. Новости вымышлены, имеют источник и факт/план; план не гарантирует будущий результат.

Персональный разбор детерминирован: сумма долларовых вкладов, лучший абсолютный прирост за раунд, средняя доля cash и максимальная доля одной позиции по сохранённым портфелям. Это описание решений участника, без AI и финансовой рекомендации. Старые event v1 сохраняют прежний рынок и проценты, не переоцениваются этой моделью.
